# lx_music(洛雪音乐音源)

lx_music音源

## ⭐ 推荐方式：使用最新音源包（本地导入）

仓库内已上传最新的音源整合包：**`0912-update.zip`**

- 下载后解压，在洛雪音乐的「音源设置」中选择**自定义音源（本地导入）**，导入对应的 `.js` 文件即可。
- **推荐使用这个音源：`lx-music-source-v6 (修复).js`**，为最新的修复版音源，测试可用。
- 压缩包内还包含其他音源（墨澜聚合、星海音乐源、野花音源、长青SVIP音源等），可根据需要自行选用。

> 测试说明：本音源包更新测试截止至 **2026年9月12日**，其中**本地音源均有效可用**；在线音源未做测试，请自行尝试。

> 上一版本：`音源接口-2026-8更新.zip`（更新测试截止至 **2026年8月24日**）。
