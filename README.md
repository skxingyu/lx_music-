# lx_music(洛雪音乐音源)

lx_music音源

## ⭐ 推荐方式：使用最新音源包（本地导入）

仓库内已上传最新的音源整合包：**`音源接口-2026-8更新.zip`**

- 下载后解压，在洛雪音乐的「音源设置」中选择**自定义音源（本地导入）**，导入对应的 `.js` 文件即可。
- **尤其推荐其中的「洛雪音乐独家音源」（本人也在使用）**，位于压缩包内的 `独家音源（推荐）` 与 `洛雪音乐-微信公众号独家音源（推荐）` 文件夹中。

> 测试说明：本音源包更新测试截止至 **2026年8月24日**，其中**本地音源均有效可用**；在线音源未做测试，请自行尝试。
